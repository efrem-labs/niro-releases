# Niro — Support

**Product website:** https://niro.efremlee.com

## Before asking

1. Read the release notes for your version:
   - iPhone: App Store → Niro → What's New
   - Mac: https://github.com/efrem-labs/niro-releases/releases
2. Make sure **Niro Bridge** is running on the Mac (menu bar icon) and the phone
   and Mac are on the same network. Wi-Fi + Tailscale are both supported.

## Where to ask

- **Bug reports / questions:** open an issue on this repository
  (https://github.com/efrem-labs/niro-releases/issues). Include: iPhone and iOS
  version, macOS version, Niro app version, Niro Bridge version, and what you did
  right before the problem.
- **Bridge crashes / notarization problems:** include the DMG file name and the
  SHA-256 from `SHA256SUMS.txt`.
- **Security:** do not post tokens, private keys or full session logs. Describe
  the issue first; we will arrange a private channel.

## Scope

This repository is the release home for **Niro Bridge** and product docs. The
Niro iPhone app source is **not** public. Requests for the app's source,
licensing or partnership go to the product website contact.
