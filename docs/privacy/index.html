English

Niro is made by Efrem Labs. This policy describes what Niro does — and does not do — with your data. It applies to the Niro iOS app, the Niro Bridge app for Mac, and this website.

In short

  • Niro does not require an account.
  • Niro does not collect personal data on Efrem Labs servers.
  • Niro connects the user's iPhone to Niro Bridge running on the user's own Mac.
  • Coding-agent sessions, provider configuration, API keys, and related data remain on the user's devices / connected providers and are not collected by Efrem Labs.
  • Niro does not use advertising SDKs or analytics SDKs.
  • Optional in-app purchases are processed by Apple through StoreKit; Efrem Labs does not receive the user's payment-card information.

Accounts

Niro does not require an account. There is no sign-up, no sign-in, and no Efrem Labs user account associated with the app.

Data collected by Efrem Labs

Niro does not collect personal data on Efrem Labs servers. The app communicates directly with the copy of Niro Bridge running on your own Mac. Efrem Labs does not receive that traffic, and there is no Efrem Labs account system or data server behind it in the current release.

How Niro connects

Niro connects your iPhone to Niro Bridge running on your own Mac, over your local network or a private network you control (for example, Tailscale). Pairing is approved by you on your Mac.

Where your data lives

Coding-agent sessions, provider configuration, API keys, and related data remain on your devices or with the providers you connect. They are not uploaded to Efrem Labs. The coding providers you use through Niro Bridge handle your data under their own terms and privacy policies.

Advertising and analytics

Niro does not use advertising SDKs or analytics SDKs.

In-app purchases

Optional in-app purchases are processed by Apple through StoreKit. Efrem Labs does not receive your payment-card information. Purchases and refunds are handled by Apple under Apple's terms.

This website

This page is served as static files by GitHub Pages from the public efrem-labs/niro-releases repository. The page sets no cookies and runs no analytics. GitHub may log requests as part of serving the site, under GitHub's own privacy statement.

Changes

If this policy changes, the updated version will be published at this address with a new "last updated" date.

Contact

Privacy questions: efremlee@icloud.com

中文

Niro 由 Efrem Labs 开发。本政策说明 Niro 会（以及不会）如何处理你的数据，适用于 Niro iOS App、Mac 上的 Niro Bridge App，以及本网站。

要点

  • Niro 不需要注册账号。
  • Niro 不会在 Efrem Labs 服务器上收集你的个人数据。
  • Niro 将你的 iPhone 连接到运行在你自己 Mac 上的 Niro Bridge。
  • Coding Agent 会话、Provider 配置、API Key 及相关数据保留在你的设备上或你连接的 Provider 处，不会被 Efrem Labs 收集。
  • Niro 不集成任何广告 SDK 或分析统计 SDK。
  • 可选的 App 内购买由 Apple 通过 StoreKit 处理；Efrem Labs 不会收到你的支付卡信息。

账号

Niro 不需要注册账号，没有注册、登录流程，App 也不关联任何 Efrem Labs 用户账号。

Efrem Labs 收集的数据

Niro 不会在 Efrem Labs 服务器上收集你的个人数据。App 直接与你 Mac 上运行的 Niro Bridge 通信，Efrem Labs 不会收到这些通信内容；当前版本也没有 Efrem Labs 的账号系统或数据服务器。

Niro 如何连接

Niro 通过你的局域网或你自己掌控的私有网络（例如 Tailscale），将 iPhone 连接到运行在你自己 Mac 上的 Niro Bridge。配对需要你在 Mac 上确认。

你的数据存放在哪里

Coding Agent 会话、Provider 配置、API Key 及相关数据保留在你的设备上或你连接的 Provider 处，不会被上传到 Efrem Labs。你通过 Niro Bridge 使用的 Coding Provider 会依据其自身的条款与隐私政策处理你的数据。

广告与分析

Niro 不集成任何广告 SDK 或分析统计 SDK。

App 内购买

可选的 App 内购买由 Apple 通过 StoreKit 处理。Efrem Labs 不会收到你的支付卡信息；购买与退款由 Apple 依据其条款处理。

关于本网站

本页面作为静态文件由 GitHub Pages 托管，来源于公开仓库 efrem-labs/niro-releases。页面不设置 Cookie，也不含分析统计。GitHub 在提供页面服务时可能会记录请求，适用 GitHub 自身的隐私声明。

政策变更

如本政策有更新，新版本会发布在同一地址，并更新"最后更新"日期。
