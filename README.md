# Niro Bridge — Releases

Public release binaries for **Niro Bridge** (macOS), the companion app for the Niro iPhone app.

## Install

1. Download `Niro-Bridge-0.1.0.dmg` below.
2. Open the DMG and drag **Niro Bridge** into **Applications**.
3. Launch it — it lives in the **menu bar** (no dock icon, no window).
4. On your iPhone, open **Niro** and tap **开始设置** to pair.

No source code is published in this repository; it hosts release binaries only.
